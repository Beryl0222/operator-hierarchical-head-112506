# 分类树与标注数据
tree_revision 引用一棵有根树。node_id 稳定，leaf_id 是独立语义身份，alias_map 将叶别名映射到规范 leaf_id；同一规范叶在树上恰有一个位置。每内部节点的边 logits 为 X @ edge_weight.T + edge_bias，对其实际子节点归一化。叶概率为路径条件概率之积，不要求特定计算方式。训练目标为允许规范叶集合概率和的负对数。只对连续特征和边参数求导。
标注含 annotation_id、document_id、issued_tree、allowed_leaf_ids、excluded_leaf_ids、revision。节点标注在签发时展开为该版节点下的叶身份并记录，之后不自动扩展。对于同文档当前有效的多条标注，允许范围取交集后去掉排除集合；冲突为空时该文档不可训练，标注撤回后重判。每文档一个正 sample_weight，不按标注条数计数。训练窗口所依赖标注或树被修改则拒绝窗口。
语义支持按当前内部节点的子分支身份划分解释，支持计数只来自已提交窗口中的有效文档：其冻结允许集合必须完全落在一个子分支且非空，才为该分支增加文档权重；同文档在同版支持历史只计一次。节点子分支语义不变可继承参数和支持，否则新分支权重按调用者提供的逐节点 initial_weights 初始化，支持清零；移动造成祖先子分支范围变化时，祖先的身份解释同样重判。参数初始化值由输入提供，不规定学习算法。
预测按调用方 min_probability 和 min_support 判断能否给出分类；一个候选节点只有自身概率合格、根至该节点每次细分的全部子分支均有 min_support 的监督支持，才能作为正式细分；从符合条件的节点取最深者，再按概率、node_id裁定。排除叶后的条件概率以剩余叶总概率作分母，原始概率不改变；空剩余集不可预测。旧预测保留旧树、参数和支持解释。
最多8192叶、深度<=16、特征维64、batch<=512，不允许 [batch,leaf,depth] 展开。临时数值区最多16 MiB，最终叶概率如明确被查询可作为输出，否则不能以输出名义常驻；头参数和输入不计。概率及损失 atol=3e-5、rtol=5e-4，梯度 atol=3e-4、rtol=2e-3。
